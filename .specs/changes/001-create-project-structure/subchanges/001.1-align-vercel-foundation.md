# Subchange 001.1 — Alinhar a fundação à Vercel

## Objetivo

Corrigir a divergência entre a arquitetura aprovada e a fundação executável, adotando o runtime padrão do Next.js para Vercel e preservando o Supabase como backend relacional.

## Escopo aprovado

- Substituir Vinext/Cloudflare pelo runtime oficial do Next.js.
- Remover exemplos e configurações de Cloudflare Workers e D1.
- Atualizar dependências e corrigir alertas de segurança conhecidos.
- Registrar Vercel e Supabase como plataformas confirmadas.
- Manter a aplicação sem funcionalidades do MVP e sem deployment público.
- Criar um commit-base reproduzível após os gates de qualidade.

## Critérios de aceite

- `dev`, `build` e `start` usam comandos oficiais do Next.js.
- Não permanecem dependências ou configurações de Vinext, Wrangler, Workers ou D1.
- Lint, typecheck, testes e build de produção passam.
- Auditoria de dependências de produção não apresenta vulnerabilidade alta.
- O projeto Supabase do Mapa continua isolado pelo Project Ref.
- Nenhum recurso Vercel é publicado nesta subchange.
