# Critérios de aceite

1. O campo do Mapa Rápido exibe exatamente o novo placeholder.
2. O texto antigo iniciado por “Exemplo:” não aparece nas superfícies do modo
   rápido.
3. Digitação, sugestões, seleção de tema e avanço permanecem funcionais.
4. Landing page e dashboard apresentam o mesmo texto.
5. Testes, lint, tipos e build passam sem regressão.
