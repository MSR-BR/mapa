# Requisitos

- Um card para o objetivo geral revisável e um para cada OE.
- Texto e orientações em duas colunas somente com espaço suficiente; uma
  coluna no tablet/celular, usando a largura disponível do contêiner.
- Ações em rodapé próprio; nunca comprimem os campos.
- Campos legíveis, contadores e ajuda sob demanda preservados.
- Manter estado das abas, edição, adição, remoção, promoção e regras de perfil.
- Sem dependências novas, APIs, migrações ou alterações de autorização.
