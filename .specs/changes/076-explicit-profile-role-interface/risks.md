# Riscos e controles

- **Reintroduzir troca de papel:** não restaurar formulários ou Server Actions de
  atualização; manter testes negativos.
- **Ocultar contexto legítimo:** conservar referências a estudante dentro da
  revisão de projetos compartilhados.
- **Exibir campo de orientador no perfil errado:** derivar a visibilidade de um
  contrato único por papel e testar os dois valores.
- **Regressão de autorização:** executar o E2E existente com contas separadas e
  confirmar isolamento, revisão e persistência entre sessões.
