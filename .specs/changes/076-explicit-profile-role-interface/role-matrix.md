# Matriz de interface por papel

| Superfície | Aluno | Orientador |
|---|---|---|
| Primeiro acesso | `Sou aluno` | `Sou orientador` |
| Menu | `Perfil da conta: Aluno` | `Perfil da conta: Orientador` |
| Área de trabalho | Criação de projetos | Revisão de projetos |
| Criar projeto próprio | Sim | Sim |
| Informar e-mail do orientador | Sim | Não |
| Enviar etapa para revisão | Sim, quando houver vínculo | Não em projeto próprio |
| Revisar projeto compartilhado | Não | Sim |
| Ver conteúdo do estudante na revisão | Não aplicável | Sim |
| Trocar papel após escolha | Não | Não |
