# Decisões

1. A C76 substitui somente o critério textual da C64 que ocultava o nome do
   perfil ativo.
2. Permanência do papel, RLS e ausência de troca continuam inalteradas.
3. `Aluno` e `Orientador` identificam o perfil; `Criação de projetos` e
   `Revisão de projetos` identificam a área de trabalho.
4. Menções a estudante são mantidas na tela de revisão do Orientador quando
   descrevem o autor real do projeto.
5. Nenhuma migration será criada para uma correção exclusivamente de interface.
