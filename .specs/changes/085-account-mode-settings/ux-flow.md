# Fluxo de experiência

```text
Menu da conta
  → Configurações
  → Modo de uso
  → escolher Aluno ou Orientador
  → confirmação com resumo do que ficará visível
  → RPC atômica
      ├─ sucesso: revalidar + avisar abas + dashboard do novo modo
      ├─ consentimento ausente: gate do novo modo
      └─ conflito: recarregar estado atual e pedir nova confirmação
```

Texto recomendado: “Você continuará na mesma conta. Seus projetos e vínculos
não serão apagados; apenas as ferramentas do perfil escolhido ficarão ativas.”
