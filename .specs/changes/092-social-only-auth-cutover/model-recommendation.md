# Modelo recomendado

- Modelo: `gpt-5.6-sol`.
- Esforço: `Extra High (xhigh)`; usar `Ultra` se estiver disponível.

A C92 é um corte de autenticação com risco direto de indisponibilidade e perda
de acesso. Exige raciocínio profundo, rastreabilidade e validação ponta a ponta
entre interface, Supabase Auth, identidades existentes e RLS.
