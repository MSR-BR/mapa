# Critérios de aceite

- [x] Reservas simultâneas respeitam teto; liquidação repetida não duplica devolução.
- [x] Uso incompleto, modelo desconhecido, timeout e cancelamento incerto não liberam dinheiro.
- [x] Anônimo, usuário diferente e segredo incorreto não podem liquidar reservas.
- [x] Resposta válida permanece disponível se a contabilização auxiliar falhar.
