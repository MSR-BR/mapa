# Modelo recomendado

- Modelo: `gpt-5.6-sol`.
- Esforço: `Extra High (xhigh)`; usar `Ultra` se estiver disponível.

A C91 cruza OAuth/OIDC, callback PKCE, identidade, configuração externa,
privacidade, RLS e continuidade de contas. O risco de bloquear usuários ou
duplicar identidades exige raciocínio e verificação aprofundados.
