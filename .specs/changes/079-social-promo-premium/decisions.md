# Decisões

1. Modelo coordenador: `gpt-5.6-sol` com raciocínio `xhigh`.
2. A C78 é uma versão imutável; nenhuma saída anterior será sobrescrita.
3. A geração de imagem fornece somente o fundo humano da abertura.
4. Marca, interface, cópia, URL e QR Code serão compostos localmente.
5. A música final será uma faixa instrumental gerada pelo catálogo Astral do
   HeyGen, identificada por ID, sem voz e sem música comercial incorporada.
6. Não haverá deploy do aplicativo, pois o escopo é um novo ativo promocional.
