# Critérios de aceite

1. A mesma conta alterna Aluno→Orientador→Aluno e mantém a escolha após login.
2. Em cada modo, somente as features da matriz C82 ficam visíveis e executáveis.
3. Projeto criado como Aluno reaparece intacto ao voltar para Aluno.
4. Projeto criado como Orientador reaparece intacto ao voltar para Orientador.
5. Orientador cria, edita, integra, exporta e conclui projeto próprio sem campo
   de orientador ou aprovação externa.
6. Projetos vinculados reaparecem intactos ao voltar para Orientador.
7. Conta B revisa projeto estudantil da conta A somente quando B está em
   Orientador.
8. Conta A lê a devolutiva somente como proprietária em Aluno.
9. Trocar para Orientador não permite à conta A editar ou autoaprovar seu projeto
   criado como Aluno.
10. Aba obsoleta recebe 403/409, atualiza o contexto e não grava nada.
11. Acesso direto à Data API respeita as mesmas negações.
12. Auto-orientação, autoria adulterada e UPDATE direto de perfil falham.
13. Suite completa, advisors, produção, health e logs ficam aprovados.
14. Não existe regressão alta/crítica nem dado de teste remanescente.
