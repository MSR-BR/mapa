# Critérios de aceite

1. Aluno vê apenas criação e projetos próprios.
2. Orientador vê apenas projetos vinculados para revisão.
3. Orientador não recebe formulário de criação nem ações de proprietário.
4. Aluno não vê projetos vinculados a ele como orientador.
5. URL incompatível não revela título, estado ou conteúdo do projeto.
6. Trocar para o outro modo revela novamente os dados preservados daquele modo.
7. Não restam branches `isAdvisorOwner` nos workspaces de Aluno.
8. Labels, estados vazios e analytics refletem o modo real.
9. Recursos comuns continuam funcionais nos dois modos.
