# Checklist de superfícies

| Superfície | Aluno | Orientador |
|---|---|---|
| Cabeçalho/menu | perfil Aluno + Configurações | perfil Orientador + Configurações |
| Hero | criação Rápida/Avançada | criação Rápida/Avançada |
| Biblioteca própria | projetos de Aluno | projetos autônomos de Orientador |
| Card próprio | abrir/duplicar/excluir/integrar | abrir/duplicar/excluir/integrar |
| Projeto próprio | editor completo + supervisão opcional | editor completo, sem supervisão |
| CTA de validação própria | “Validar etapa” | “Validar etapa” |
| Área vinculada | ausente | “Projetos orientados” |
| Card vinculado | ausente | abrir revisão, sem mutações de proprietário |
| Projeto vinculado | ausente | leitura, comentário, correção, aprovação |
| Exportação | disponível para próprios | disponível para próprios |
| Estado vazio | convite para criar | convites separados para criar e receber vínculo |
| Lembrete | enviar ao orientador | enviar ao estudante somente em projeto vinculado |
