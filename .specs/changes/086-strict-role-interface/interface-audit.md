# Checklist de superfícies

| Superfície | Aluno | Orientador |
|---|---|---|
| Cabeçalho/menu | perfil Aluno + Configurações | perfil Orientador + Configurações |
| Hero | criação do mapa | fila de revisão |
| Biblioteca | próprios em andamento/concluídos/integrados | somente vinculados |
| Card/modal | abrir/duplicar/excluir/integrar | abrir revisão, sem mutações de dono |
| Projeto | editor completo + orientador | leitura, comentário, correção, aprovação |
| Exportação | disponível para próprios | ausente |
| Estado vazio | convite para criar | instrução para receber vínculo |
| Lembrete | enviar ao orientador | enviar ao estudante |
