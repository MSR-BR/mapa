# Notas

- “Apenas features de orientador” substitui a decisão da C76 que permitia ao
  Orientador criar projetos próprios.
- Uma pessoa que já criou projetos enquanto era Orientador não perde os dados;
  eles aparecem ao selecionar Aluno.
- Ocultar interface é requisito de UX, não controle de segurança; C84 e C87 são
  obrigatórias para o resultado ser considerado robusto.
