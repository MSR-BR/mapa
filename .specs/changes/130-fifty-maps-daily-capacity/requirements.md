# Requisitos

1. Meta de 50 percursos completos/dia sem cota diária por aluno; medir revisões, falhas e uso opcional.
2. Aumento de orçamento autorizado pelo usuário em 23/10: teto inicial escolhido US$100/mês, sem recarga ou compra; contador existente preservado.
3. US$100 comportam 1500 mapas a US$0,05 mais US$25 de margem: cenário de planejamento, não medição de percursos completos.
4. Cotas reais dos provedores e conclusão de 50 mapas permanecem pendentes até verificação; não declarar capacidade comprovada só pelo novo teto.

Não alterar Ads/GA4, chaves, textos dos usuários ou controles de orientação. Sem quota diária de mapas.
