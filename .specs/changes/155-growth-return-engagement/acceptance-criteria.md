# Critérios de aceite

- Cada proposta indica gatilho, público, mensagem, efeito esperado, custo/risco e medida de resultado.
- A métrica de retorno exige avanço posterior, não apenas abrir o app.
- Papel de aluno/orientador, projeto concluído e pendência legítima têm regras distintas.
- Nenhum contato é enviado e nenhuma configuração de consentimento é mudada.
