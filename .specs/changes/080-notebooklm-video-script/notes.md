# Notas

- O formato recomendado é `Video Overview` do tipo `Brief`, em português do
  Brasil.
- A marca de 45–60 segundos é um alvo narrativo, não uma garantia de duração da
  plataforma.
- O NotebookLM deve receber apenas fontes selecionadas e aprovadas do projeto.
- Como a saída é generativa, narração, duração e enquadramentos podem variar.
- A versão final para redes sociais exige uma etapa posterior de edição para
  aplicar logo, textos e QR Code exatos.
- A execução no NotebookLM e a pós-produção não fazem parte desta Change.
