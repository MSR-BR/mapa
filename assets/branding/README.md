# Identidade visual

Os três arquivos em `originals/` são as fontes recebidas para a identidade do Mapa da Pesquisa e ficam preservados para usos futuros.

As versões transparentes em `public/brand/` são as cópias preparadas para a interface:

- `mapa-da-pesquisa-wordmark.png`: assinatura horizontal para cabeçalhos e landing page.
- `mapa-da-pesquisa-mark.png`: símbolo isolado para a tela inicial e usos compactos.
- `mapa-da-pesquisa-app-icon.png`: símbolo em fundo escuro para autenticação, ícone do app e favicon.

O componente `modules/branding/brand-logo.tsx` concentra o uso das marcas para evitar variações acidentais entre telas.
