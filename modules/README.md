# Módulos de domínio

Esta pasta receberá módulos coesos por capacidade do produto. Cada módulo deve expor uma API pública pequena e não pode acessar detalhes internos de outro módulo.

Módulos previstos: autenticação, projetos, briefing, geração, editor, exportação e adaptador Research Starter. Eles serão criados somente nas changes correspondentes.
